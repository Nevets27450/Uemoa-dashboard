# UEMOA — Explorer les économies

Dashboard Power BI consacré aux huit pays de l’UEMOA : vue d’ensemble, évolution économique, revenus, commerce extérieur et focus sur le Bénin.

## Ouvrir le dashboard

1. Ouvrir `Uemoa.pbip` dans une version récente de Power BI Desktop compatible PBIP/PBIR.
2. Conserver les dossiers `Uemoa.Report` et `Uemoa.SemanticModel` à ses côtés.
3. Dans **Transformer les données → Gérer les paramètres**, renseigner `DossierDonnees` avec le dossier contenant `donnees_uemoa_large.csv` et `smig_uemoa_2025.csv`.
4. Actualiser les données. Les CSV et le cache Power BI ne sont pas inclus dans le dépôt.

## Repères

- Données économiques : 1960–2024, en USD courants.
- SMIG : source datée de 2025, annualisée et convertie au taux fixe de 564,98 FCFA/USD.
- PIB par habitant régional : PIB total divisé par la population totale.
- Nuage de points : visuel personnalisé dont le chargement peut nécessiter un accès réseau.

Les sources d’origine et les conditions de réutilisation des CSV restent à documenter.
